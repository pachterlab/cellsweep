# Every run that produces the panels of the paper's figures, in dependency order.

# then assemble the figures with: python scripts/paper_figures/make_figures.py
#
# Every job reuses outputs that already exist unless OVERWRITE=True; after a model change, rerun with OVERWRITE=True
# (other tools are not rerun either way, since rerun_tools=False). Figure names below are the file names in the paper
# repo's Figures/ directory, which follow the figure numbers in the text (Supp<n>.pdf is Fig. S<n>).
# The notebooks download any data they need.
