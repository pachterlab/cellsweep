# More notebooks

The [`notebooks/`](https://github.com/pachterlab/cellsweep/tree/main/notebooks) folder of
the repository has the notebooks behind the analyses in the CellSweep paper. They need
`pip install "cellsweep[analysis]"` and, for most of them, the datasets they download.

| Notebook | Topic |
| --- | --- |
| [`intro.ipynb`](https://github.com/pachterlab/cellsweep/blob/main/notebooks/intro.ipynb) | End-to-end PBMC example (rendered in {doc}`intro`) |
| [`simulations.ipynb`](https://github.com/pachterlab/cellsweep/blob/main/notebooks/simulations.ipynb) | Benchmarks on simulated data |
| [`benchmarking.ipynb`](https://github.com/pachterlab/cellsweep/blob/main/notebooks/benchmarking.ipynb) | Comparison with other denoising tools |
| [`technologies.ipynb`](https://github.com/pachterlab/cellsweep/blob/main/notebooks/technologies.ipynb) | Different sequencing technologies |
| [`8cube.ipynb`](https://github.com/pachterlab/cellsweep/blob/main/notebooks/8cube.ipynb) | 8cube mouse tissue atlas |
| [`spatial.ipynb`](https://github.com/pachterlab/cellsweep/blob/main/notebooks/spatial.ipynb) | Spatial transcriptomics |
| [`janssen_snrna.ipynb`](https://github.com/pachterlab/cellsweep/blob/main/notebooks/janssen_snrna.ipynb) | Single-nucleus RNA-seq |
| [`melanoma_discovery.ipynb`](https://github.com/pachterlab/cellsweep/blob/main/notebooks/melanoma_discovery.ipynb) | Melanoma case study |
| [`granularity.ipynb`](https://github.com/pachterlab/cellsweep/blob/main/notebooks/granularity.ipynb) | Sensitivity to cell-type label granularity |
| [`parameter_sweep.ipynb`](https://github.com/pachterlab/cellsweep/blob/main/notebooks/parameter_sweep.ipynb) | Hyperparameter sensitivity |
| [`idempotency.ipynb`](https://github.com/pachterlab/cellsweep/blob/main/notebooks/idempotency.ipynb) | Re-running CellSweep on its own output |
| [`runtime.ipynb`](https://github.com/pachterlab/cellsweep/blob/main/notebooks/runtime.ipynb) | Runtime and memory |
